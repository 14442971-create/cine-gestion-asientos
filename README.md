# Sistema de Administración de Asientos de Cine

## 📌 Descripción del Proyecto
Este proyecto es una aplicación de consola en C# orientada a digitalizar la administración de asientos en una sala de cine utilizando una matriz bidimensional. Permite visualización en tiempo real, reserva, liberación, consulta de disponibilidad y generación de estadísticas de ocupación de la sala para prevenir duplicidad de reservas.
